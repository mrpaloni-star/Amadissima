# Amadíssima Estética

Site institucional da Amadíssima, com páginas de serviços, depilação a laser e agendamento por WhatsApp.

## Arquivos

- `index.html`: página inicial.
- `depilacao-a-laser.html`: informações e dúvidas frequentes.
- `agendamento.html`: opções de atendimento e links de agendamento.
- `assets/`: imagens do site.

Site estático em HTML, CSS e JavaScript. Não requer compilação. Para visualizar localmente, execute `python -m http.server 8000` nesta pasta e abra http://localhost:8000.

Versão importada do projeto Amadíssima no ChatGPT Sites e publicada na Wix em 29/10/2026. O envio ao GitHub não ativa automaticamente o GitHub Pages.
